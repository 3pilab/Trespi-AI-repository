# Chained pull requests skill

Splits work over about 400 changed lines into chained pull requests, stacked to main or as a feature-branch chain with
a tracker.

- Read **`SKILL.md`** for the rules, decision gates, and steps.
- Read **`chaining-details.md`** for branch diagrams, the Chain Context section, and commands.
- The usage guide, the flow diagram, and example prompts for Claude Code, Cursor, and Agent Hub live in
  [odd-rdd-help/guide.md](../odd-rdd-help/guide.md).
