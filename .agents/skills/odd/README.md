# ODD skill

Organic Driven Development: the default workflow for every request — authorize, explore, resolve uncertainty, classify
by task size, track large work in one feature document, implement task by task, and close with verified results.

- Read **`SKILL.md`** for the protocol in order.
- Read **`task-size.md`**, **`research.md`**, **`feature-document.md`**, **`delegation.md`**, **`test-first.md`**, and
  **`delivery.md`** when the step they cover comes up.
- The usage guide, the flow diagram, and example prompts for Claude Code, Cursor, and Agent Hub live in
  [odd-rdd-help/guide.md](../odd-rdd-help/guide.md).
