# Work-unit commits skill

Makes every commit one reviewable unit — a behavior with its tests and docs, a rollback boundary, and recorded
verification — so commits become RDD review candidates and chained pull request slices.

- Read **`SKILL.md`** for the rules, the pre-commit checklist, and how ODD uses work units.
- The usage guide, the flow diagram, and example prompts for Claude Code, Cursor, and Agent Hub live in
  [odd-rdd-help/guide.md](../odd-rdd-help/guide.md).
