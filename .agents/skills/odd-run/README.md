# ODD Run skill

Runs the whole Organic Driven Development flow on one request in one invocation, stopping only at the gates where you
must answer.

- Read **`SKILL.md`** for the flow diagram, the gates, resuming with "continue", and the final report.
- The usage guide, the flow diagram, and example prompts for Claude Code, Cursor, and Agent Hub live in
  [odd-rdd-help/guide.md](../odd-rdd-help/guide.md).
